# Playwright-Java Automation Framework

A test automation framework built with Playwright and Java, covering UI automation and API testing.

## Features
- UI automation: navigation, form filling, dropdowns, checkboxes
- Page Object Model (POM) design pattern
- API testing: GET, POST, PUT requests with status code validation
- Built with Maven, JUnit 5

## Tech Stack
- Java
- Playwright
- Maven
- JUnit 5
